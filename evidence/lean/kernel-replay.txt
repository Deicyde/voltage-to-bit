Where the tools come from
  The script runs with an environment of its own (HOME, PATH, TMPDIR). `lean` is found
  through PATH in the project directory; every Lean tool is then run from the bin directory
  of that toolchain (`lean --print-prefix`) and from nowhere else. A tool that is not there
  is reported as NOT RUN and is not counted.
  `lake help check` of this toolchain says about the checkers it bundles:
    --paranoid also run all external checkers bundled with Lean besides Lean's own kernel: `leanchecker-paranoid`, `lean4lean`, `nanoda`, `con-leche` and `con-ron`
