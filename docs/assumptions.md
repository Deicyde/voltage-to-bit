## How to read it

A label is not evidence. Each row has two separate fields:

- **Evidence type** says what kind of support the item could have.
- **Discharge status** says whether that support is actually in hand.

| Type | Meaning in this register |
| --- | --- |
| definition | A choice of words or numbers. Nothing to prove. Its relation to the physical world is always a separate row. |
| proved consequence (Lean) | Follows from the definitions and is a declaration of the library at the pinned commit. |
| derived by hand, or scratch | Follows from the definitions by a derivation, or by a Lean file, that is not part of the library. The row says which. |
| environment restriction | A condition on the inverter's surroundings that the project chooses to assume. It narrows the claim. Only the user of the theorem can discharge it. |
| reference data | A figure or a piece of code read in a cited document: vendor documentation, a model card, a standard, third-party source code. Not an observation by this project and not a measurement of a device. |
| numerical observation of the model | Output of this project's own computations on the formal model or on perturbed versions of it. Finite coverage. Not a theorem and not evidence about a device. |
| physical evidence | A measurement of a device, or a comparison with a model of a real device, such as the SKY130 BSIM4 cards (tier T3 of `M` §9.4). A simulator run of the formal law (tier T1), or of the formal model with one omitted effect switched back on (tier T2), is not. No row has this type. |
| unresolved assumption | A claim about the physical world, or about a reference model, that the physical reading needs and that nobody has established. |

The handoff names five types. Its fourth, "empirical evidence", is split here into the three types "reference data", "numerical observation of the model" and "physical evidence", so that the first two cannot be read as the third. A finite sample never discharges a statement quantified over a continuum.

Rules for row IDs. An ID never changes its meaning. A row may be rewritten or split. A retired row stays as a one-line stub that says why. New rows are added at the end of their table.

No row assigns a value to a residual bound (`ε_m`, `ε_off`). None has a justification.

Notation.

- `psq(x) = max(x, 0)²`. `abs(x)` is the absolute value. Units are V, µA, fF, ns and µA/V².
- Lean names are written relative to the namespace `VoltageToBit`, and file names relative to the directory `VoltageToBit/`. Names of the examples carry the prefix `Examples.`. Inside a quoted expression the prefix `Examples.` is dropped, except on the left-hand sides of the defining equations in DEF-12.
- Lean expressions are quoted with `abs (x)` where the source has absolute-value bars, and without the type annotations of bound variables. A hypothesis is quoted as `name : statement`, with the name it has in the source.
- Prose formulas use the symbols of `docs/interface.md`. They correspond to the fields of a record `D : Design` as follows.
