# Allow-list of scripts/SourceScan.lean and scripts/Audit.lean: what the source files
# and the compiled files of the library may contain.
#
# The lists hold what the library uses now, and nothing else. Anything that is not
# listed is refused by scripts/check.sh, by name (step source-scan for the first four
# kinds of line, step axiom-audit for the last). To admit something, add a line here
# by hand, in a commit that says why. The records name the entries that nothing uses
# (evidence/lean/source-scan.txt and evidence/lean/audit.txt).
#
#   command <kind>    a kind of command, as Lean's parser names it
#   node <kind>       a kind of syntax node inside a command
#   char U+XXXX       a character besides printable ASCII and line feed, anywhere in a
#                     file, comments included (what follows the code point is a note)
#   max-column <n>    no code token may end beyond this column
#   extension <name>  an environment extension of Lean in which the compiled files of
#                     the library may have entries. The entries of the instance and
#                     simp extensions are looked at one by one by scripts/Audit.lean:
#                     only what Lean generates for a structure is accepted there.
#
# Not listed on purpose, because each can change what later text means, hide a
# hypothesis, or run code when a file is compiled:
#   commands: every command other than the seven below. So no `section`, `universe`,
#     `set_option`, `attribute`, `notation`, `infix`, `macro`, `syntax`, `elab`,
#     `deriving instance`, `export`, `include`, `omit`, `mutual`, `#eval`, `#exit`,
#     `run_cmd`, `initialize`, `open ... in`, and no command that Mathlib defines
#     (`variable?`, `alias`, `lemma`, ...).
#   nodes: attributes (`@[...]`), `axiom`, `opaque`, `instance`, `abbrev`, `class`,
#     `inductive`, `example`, `deriving`, `unsafe`, `partial`, `protected`, instance
#     binders `[...]`, strict implicit binders, default values and `by` blocks of
#     binders, `where` declarations, `@f`, `sorry`, `decide`, `native_decide`, every
#     item of a tactic configuration (`+opt`, `-opt`, `(opt := v)`), `set_option ... in`,
#     `open ... in`, `Type`, `Sort`, string, character and name literals, quotations.
#   extensions: those that hold parsers, macros, elaborators, notation, aliases and
#     the attributes of Mathlib's tactics; the library has no entry in any of them.
